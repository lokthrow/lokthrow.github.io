Sobre mí

Un desarrollador, de principio a fin

Empecé haciendo apps nativas: TDiary lo escribí en Java para Android y en Swift para iOS. Mantener dos bases de código para una sola persona es mucho trabajo, así que me pasé a React Native. Desde entonces todas mis apps comparten una única base de código en TypeScript.

Me gusta resolver problemas concretos. MiraBolsa nació porque consultar la posición en las bolsas de interinos obligaba a entrar en un portal distinto por cada comunidad. Para y Siente salió de trabajar con Mónica, psicóloga, en una herramienta para gestionar las emociones en el día a día.

React Native

Apps multiplataforma con TypeScript y actualizaciones OTA para corregir y avanzar rápidamente.
